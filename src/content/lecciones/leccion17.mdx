# Formulario de la elipse

| Elemento              | Fórmula horizontal                              | Fórmula vertical                                |
| --------------------- | ----------------------------------------------- | ----------------------------------------------- |
| Ecuación ordinaria    | \\(\frac{(x-h)^2}{a^2}+\frac{(y-k)^2}{b^2}=1\\) | \\(\frac{(x-h)^2}{b^2}+\frac{(y-k)^2}{a^2}=1\\) |
| Centro                | \\(C(h,k)\\)                                    | \\(C(h,k)\\)                                    |
| Vértices              | \\(V(h\pm a,k)\\)                               | \\(V(h,k\pm a)\\)                               |
| Co-vértices           | \\(B(h,k\pm b)\\)                               | \\(B(h\pm b,k)\\)                               |
| Focos                 | \\(F(h\pm c,k)\\)                               | \\(F(h,k\pm c)\\)                               |
| Distancia focal       | \\(c=\sqrt{a^2-b^2}\\)                          | \\(c=\sqrt{a^2-b^2}\\)                          |
| Semieje mayor         | \\(a=\sqrt{a^2}\\)                              | \\(a=\sqrt{a^2}\\)                              |
| Semieje menor         | \\(b=\sqrt{b^2}\\)                              | \\(b=\sqrt{b^2}\\)                              |
| Eje mayor             | \\(2a\\)                                        | \\(2a\\)                                        |
| Eje menor             | \\(2b\\)                                        | \\(2b\\)                                        |
| Distancia entre focos | \\(2c\\)                                        | \\(2c\\)                                        |
| Lado recto            | \\(LR=\frac{2b^2}{a}\\)                         | \\(LR=\frac{2b^2}{a}\\)                         |
| Excentricidad         | \\(e=\frac{c}{a}\\)                             | \\(e=\frac{c}{a}\\)                             |
| Área                  | \\(A=\pi ab\\)                                  | \\(A=\pi ab\\)                                  |
| Centro en el origen   | \\(\frac{x^2}{a^2}+\frac{y^2}{b^2}=1\\)         | \\(\frac{x^2}{b^2}+\frac{y^2}{a^2}=1\\)         |

## Significado de las letras

| Letra    | Significado                      |
| -------- | -------------------------------- |
| \\(h\\)  | Coordenada \\(x\\) del centro    |
| \\(k\\)  | Coordenada \\(y\\) del centro    |
| \\(a\\)  | Semieje mayor                    |
| \\(b\\)  | Semieje menor                    |
| \\(c\\)  | Distancia del centro a cada foco |
| \\(e\\)  | Excentricidad                    |
| \\(LR\\) | Longitud del lado recto          |

Fórmula fundamental:

\\[ \boxed{a^2=b^2+c^2} \\]

Importante: \\(a>b>0\\). Si el denominador mayor está debajo de \\(x\\), la elipse es horizontal; si está debajo de \\(y\\), es vertical.
